## SQ-32

- External reapply preserves pending entry and the user's configured delay. Admitted work uses a bounded partial wakelock through core and deferred feature completion; cancelled or unverified results get one ordinary delayed retry, never a retry loop.
- Already-foreground reapply skips foreground re-promotion. Other on-start promotion denials are caught and journaled as FOREGROUND_START_DENIED.
- Admitted external timeouts and unknown readbacks report UNVERIFIED rather than a definite failure. Definite command failures remain FAILED; exit zero still requires readback.
- External-call journal entries are limited to ten detailed events per action per rolling minute, with suppressed counts coalesced on the next admitted event.
- BootCompleteReceiver ignores null/unrelated actions; only boot, locked boot, and own-package replacement are accepted.
- JVM coverage includes rolling-window/coalescing independence, admitted command-deadline outcomes, and service/receiver source wiring. Actual CPU suspend, API 31+ foreground restrictions, and broadcast delivery remain physical-device seams.
