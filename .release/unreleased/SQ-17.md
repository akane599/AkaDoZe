## SQ-17

- Main screen access card: current mode (Root / Shizuku (shell) / Shizuku (root) / No privileged access), live-region status, problems list, one context action (grant helper permissions with a per-item, readback-checked result; grant Shizuku permission; open Shizuku; ADB commands) and a recovery-debt warning with "Restore now" (service ledger reconcile).
- Settings availability now comes from CapabilityResolver for the current access level, API level and grants. Unavailable features are disabled with the reason (requires root / Shizuku not running / permission missing / DUMP / WRITE_SECURE_SETTINGS / Android version / unverified); stored values are never changed by gating. Root-only features are tagged "Root" in Shizuku mode. An "Access" entry at the top of Settings shows the state and runs the fix action.
- New settings: Keep Doze enforced, Summary notification after screen-on (asks for notification permission on Android 13+), and an "Other apps" group with the external start/stop and whitelist/settings gates (privileged gate warns and stays off by default).
- Switching to Shizuku shows progress until Shizuku answers the permission prompt; a denial reverts to the previous mode with an explanation.
- The auto-rotate/brightness workaround setting is retired (disabled, saved value kept). The music whitelist setting says when notification access is missing. Tasker help lists only settings the external policy accepts and shows each gate's state.
- Service notices on the existing tips channel: access lost while dozing (with "Open Shizuku"), silent update when access returns, restoration debt with a Restore action, first rejected external call per gate, and service start denied. Nothing is posted without notification permission.
